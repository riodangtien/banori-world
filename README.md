# BANORI World

BANORI brand identity landing page with an interactive 3D world.

https://riodangtien.github.io/banori-world/

## Editable world

The React/Three.js source lives in `world-src`. Run `npm ci`, `npm test` and `npm run build` there. The build writes directly to `forest` with relative URLs for GitHub Pages. Serve the repository root with any static HTTP server to preview the complete landing page at `/#world`.

Research, license decisions and preservation choices are documented in [research-notes.md](research-notes.md), [world-architecture-plan.md](world-architecture-plan.md) and [asset-credits.md](asset-credits.md). A Kenney canvas tent and two Quaternius animated animals ship under CC0; all other world geometry is generated by project source.

The default overview offers drag orbit, day/night, clear/rain/snow, summer/autumn/winter, landmark camera destinations and animation pause. Reduced-motion preferences pause environmental animation initially. Rendering stops when the parent switches away from the world. Narrow screens use capped DPR, fewer grass details and smaller water reflection/refraction targets.

No change is published automatically. The static `forest` directory is ready for the repository's existing GitHub Pages publishing workflow after review.

The environment quality audit is in [WORLD-AUDIT.md](WORLD-AUDIT.md). Final automated checks and visual evidence are in [validation.md](validation.md), [placement-validation.json](placement-validation.json) and `qa/`. The source now includes bounds grounding, shared footprint validation, a rebuilt lookout and guardian camp, rooted ancient tree, variable-width water, animated wildlife, flowing/reflected/refracted surfaces, precipitation, fireflies and complete-island camera presets.

## Playable character

ENTER WORLD uses Quaternius's CC0 Man in Long Sleeves. WASD moves, Shift runs, Space jumps, drag rotates the camera, and Escape exits. V switches between third person and first person with a held camera; F or CHỤP ẢNH captures a clean PNG, available through LƯU ẢNH. Touch devices have a joystick and jump button. Small decorations no longer block movement; low rocks and logs can be jumped over, and movement slides along solid obstacles. Wildlife includes three deer, three foxes, four rabbits, four frogs, six birds, twelve fish and density-scaled butterflies. Ground animals occupy fourteen separate habitats, with birds and butterflies spread across four flight areas. Gentle intermittent bird and frog sounds start automatically, with the first trusted interaction unlocking audio if browser autoplay policy requires it. There is no audio toggle or Quality selector; render quality adapts automatically. Audio fades with the visible portion of the World and reaches silence when scrolled away or hidden. See [play-mode-validation.md](play-mode-validation.md) and [asset-credits.md](asset-credits.md).
